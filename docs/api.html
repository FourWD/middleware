API & Integration

The library mounts a fixed set of operator/lifecycle routes on every Fiber app it builds, defines the on-the-wire response envelope, and bundles clients for the third-party services every Pakkad backend shares (Firebase, Pub/Sub, Cloud Storage, Mailgun, Sentry, OTel). All business endpoints belong to the consuming service and are mounted by its RouteRegistrar.

4.1 Endpoints / Commands

Routes mounted automatically by NewApp

Mounted in registerDefaultRoutes. Both are unauthenticated; Auth V2 auto-exempts them (BR-8).

MethodPathPurposeResponse
GET /_ah/warmup App Engine warmup hook. Always 200 so the instance is marked ready before traffic is routed. {"status":1,"code":"0000","message":"warm-up request succeeded"}
GET /wake-up Returns running build identity. Consumed by the GAE version watcher and any external "is this the version I expected?" check. {"status":1,"message":"success","data":{"app_id":"…","app_version":"…","env":"…"}}

Routes mounted by RegisterStandardRoutes

Opt-in: call from the registrar with a HealthReport provider. /livez, /healthz, /readyz and /metrics are also auto-exempt from Auth V2.

MethodPathPurposeAuth
GET/livezProcess is alive (no dependency checks).none
GET/healthzHealth report; 503 when HealthReport.Healthy() is false.none
GET/readyzSame payload/semantics as /healthz; separated so k8s/GAE can distinguish liveness from readiness.none

Response envelope

Every JSON response — whether from WriteSuccess / WriteErrorEnvelope, from AppErrorHandler (Fiber's global error path), or from /healthz — uses the same shape (BR-9): 

// success
{
  "success": true,
  "data": { … }
}

// error
{
  "success": false,
  "error": {
    "code": "INVALID_TOKEN",
    "message": "invalid or expired session"
  }
}
Note — setting HTTP_ENVELOPE_ENABLED=true turns on a fallback middleware that wraps raw JSON responses (handlers that called c.JSON(…) directly instead of WriteSuccess). New code should prefer the explicit helpers — the wrapper is a compatibility shim for handlers migrating off the legacy format.

4.2 3rd-Party Services

Each integration is opt-in via env. When the enable flag is false (or the credentials file is empty) the client is not constructed and the corresponding deps.* field stays nil — the service is responsible for nil-checking before use.

Firebase (Firestore + Auth + FCM)

  • Auth — service-account JSON at FIREBASE_CREDENTIALS; client built once via firebase.NewApp.
  • Modules — firebase.App.Firestore() for Firestore, firebase.App.Auth() for ID-token verification, FIREBASE_NOTIFICATION_CREDENTIALS for the FCM messaging client (can be the same file).
  • Failure — startup error if credentials are present but invalid; if both env vars are empty the client is simply not built.

Google Cloud Pub/Sub (v2)

  • Auth — PUBSUB_CREDENTIALS_FILE (or ADC on GAE/GCE).
  • Boot guard — PUBSUB_ENABLED=true requires PUBSUB_PROJECT_ID; missing project ID fails fast.
  • Client — NewPubSubClient wraps cloud.google.com/go/pubsub/v2; registered as deps.Cloud.PubSub; close hook runs at shutdown.

Google Cloud Storage

  • Auth — STORAGE_CREDENTIALS_FILE (or ADC).
  • Boot guard — STORAGE_ENABLED=true requires STORAGE_BUCKET.
  • Client — deps.Cloud.Storage exposes the wrapped *storage.Client with the bucket pre-bound.

Mailgun

  • Auth — MAILGUN_DOMAIN + MAILGUN_API_KEY.
  • Boot guard — both env vars required when MAIL_ENABLED=true.
  • Client — deps.Integrations.Mail.

Sentry & OpenTelemetry

  • Sentry — configured via SENTRY_DSN / SENTRY_ENV; SetupSentry registers the transport and a flush hook for shutdown. The Fiber middleware reports panics.
  • OTel — configured via the standard OTEL_EXPORTER_OTLP_ENDPOINT family. SetupOTel builds the OTLP HTTP exporter, a tracer provider, and a meter provider; the GORM plugin and Fiber middleware emit spans automatically. Shutdown flushes pending spans within the bounded shutdown budget.

Optional business integrations bundled in common/

These are legacy helpers retained for compatibility with older services; new services should call the third-party API directly from their own package rather than reach through middleware/common.

  • 2C2P payment — common/payment_2c2p*.go; configured via PAYMENT_2C2P_* env vars (request, inquiry, refund URLs + merchant ID + secret).
  • OTP / SMS — common/otp.go; configured via OTP_URL_REQUEST, OTP_URL_VERIFY, OTP_SMS_KEY, OTP_SMS_SECRET.
  • Upload service — common/upload*.go; configured via UPLOAD_SERVICE_URL, UPLOAD_TOKEN.
  • Discord — common/discord.go; webhook notifications.

4.3 Auth & Security

JWT lifecycle

Tokens are HS256-signed via JWT_SECRET; refresh tokens are tracked in a RefreshTokenStore (see 3.2.3) and rotated one-shot. JWT_ISSUER always equals APP_ID (BR-1); cross-service token reuse is impossible because the issuer is part of the refresh-token unique index.

OperationMethodPersisted
Issue pairTokenManager.GeneratePair(ctx, user)Refresh jti stored with TTL.
Validate accessTokenManager.ParseAccessToken(s)Checks signature, exp, token_type == "access".
Rotate refreshTokenManager.Refresh(ctx, s)Revokes presented jti; issues new pair; stores new jti.
Revoke refreshTokenManager.RevokeRefreshToken(ctx, s)Deletes the jti from the store.
Blacklist accessBlacklistStore.Add(ctx, token, expiresAt)Stored with TTL matching the token's remaining lifetime; Auth V2 consults on every request.

Auth V2 middleware

AuthenticationMiddlewareV2 requires Authorization: Bearer <jwt> on every request that is not in the exempt set. The exempt set is the union of three lists:

  1. Library built-ins: /_ah/warmup, /wake-up, /livez, /readyz, /healthz, /metrics.
  2. HTTP_PUBLIC_PATHS env (CSV, exact-match).
  3. AuthMiddlewareV2Config.ExemptPaths from the registrar.

OPTIONS requests skip the gate so CORS preflight is never blocked. Matching is exact — no prefixes, no regex (BR-8). The validated identity is exposed to handlers via AuthSessionFrom(ctx) as { UserID, Email, Role, ExpiresAt }.

Warn — the blacklist check is fail-open on store errors. A transient Mongo blip never locks every authenticated user out — the cryptographic verification still passed. Switch to fail-closed only for endpoints where revocation must be authoritative (e.g. by wrapping the handler with an explicit blacklist check).

Role gates

AdminOnly(role, handler) wraps a handler so it runs only when AuthSession.Role == role. No session in context returns 401 MISSING_TOKEN; wrong role returns 403 FORBIDDEN. Mount at registration time: 

v1.Delete("/users/:id", infra.AdminOnly("Admin", deps.Handlers.Users.Delete))

Rate limit

Three tiers, selected at route registration. The Redis-backed RateLimitStore uses an atomic Lua script (INCR + conditional EXPIRE); when Redis is disabled the in-memory store takes over (per-pod, swept every 30 s).

Security headers & CORS

  • CORS — HTTP_ALLOW_ORIGINS (CSV; * by default). Mounted by RegisterStack.
  • Security headers — X-Frame-Options: DENY, X-Content-Type-Options: nosniff, and friends are applied by infra/security_headers.go.
  • Proxy header — HTTP_PROXY_HEADER (e.g. X-Forwarded-For) makes Fiber trust the upstream IP so request logs and rate-limit subjects are accurate behind a load balancer.

Secrets management

Secrets are loaded only from environment variables — .env.{APP_ENV} files locally, Secret Manager / GAE env at runtime. The library never reads or writes config from a network source. HTTP_DEBUG_AUTH_TOKEN must be ≥ 16 chars when set; debug routes are wholly disabled when APP_ENV=prod.

Database grants

The library opens connections with whatever credentials the service provides — it does not assume or grant privileges. The two Mongo collections it owns need find + insert + delete + createIndex. Lack of createIndex is non-fatal: EnsureIndexes logs a warning and the operator can create the indexes out of band.

These leave the service even when the registrar contributes no code of its own. All follow the envelope shape from §4.1.

Service-defined errors

Handlers should return *infra.AppError (or wrap with ErrBadRequestWrap) so AppErrorHandler translates them to envelopes automatically. The service picks the code string; convention is uppercase snake-case, scoped to the domain (e.g. USER_NOT_FOUND, VEHICLE_LOCKED). 

if err := repo.Find(id); err != nil {
    return infra.ErrNotFound("USER_NOT_FOUND", "user does not exist")
}

Sentinel errors exported by the library

  • infra.ErrInvalidToken — generic JWT validation failure.
  • infra.ErrInvalidTokenType — access/refresh mismatch.
  • infra.ErrRevokedToken — refresh token already used or revoked.
  • infra.ErrMissingAuthorization — empty Authorization header (ParseBearerToken).
  • infra.ErrInvalidAuthorization — header not in Bearer ... form.
